# Contributing to Cloud Misconfiguration AI

Thank you for your interest in contributing to **Cloud Misconfiguration AI**!

## 🚀 How to Contribute
1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Cloud-Misconfiguration-AI.git
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/new-cloud-rule
   ```
4. **Run Security Scans and Unit Tests**:
   ```bash
   npm run scan
   npm test
   ```
5. **Submit a Pull Request** with a detailed description of your changes.
